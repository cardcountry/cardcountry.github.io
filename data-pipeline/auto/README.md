# META LAB 持久增量采集

此目录实际抓取公开来源并持久化，不依赖访客打开浏览器。每日08:17（马来西亚时间）运行GitHub Actions；官方资讯间隔24小时，日本与国际GCG卡表间隔72小时。配置推送和手动启动会强制重新核验一次，保证解析器修复不会被旧ETag挡住。

`sources.json`列出来源、原文语言、允许域、解析器、频率与批次上限。目前启用12个官方资讯索引和2个GCG赛事接口，覆盖七分类及日文、英文、繁体中文。3个尚未能可靠导入的发现入口明确禁用。新增来源须先核对真实结构、原帖链接与日期，不能把访问日期当作发布日期。

`refresh.mjs`执行条件请求、最多3次有限重试、体积上限、来源核验、去重与防日期倒退，再构建资讯索引和检查资源版本。中断后保留逐来源检查点；旧锁只在进程已退出或可信CI旧运行时恢复。缓存和checkout不一致时会重新抓取，不让失败推送留下的ETag造成漏收。

`approved.json`只包含核实过标题、日期（可明确缺失）和链接的公开索引记录；证据保留真实抓取URL、时间、正文hash和适配器版本。官方索引核验不代表已抓取Instagram等原帖内文。未到实际发布时间、格式冲突、未知卡号及残缺配方只进入运行目录的待核队列，不猜补。

GCG适配器按主牌50张、可识别卡号、数量及明确来源核验，并区分日本和其他地区；不做官方合法性认证、不推断未知印刷语言。每源每批最多100场／1000份主牌表，现有人工事件字段和结果优先，同一玩家/名次出现不同牌表时待核验。输出`auto-data/gcg-events.json`和`gcg-auto-events.js`；当前目录没有完整卡图图库自动下载器，也不自动识别不完整照片。

`publish.mjs`只允许提交五个生成文件，远端main有变化时拒绝覆盖。推送后显式请求Pages构建、等待对应commit成功，并逐文件核对正式域名SHA；没有变化时不改汇总日期、不重复发布。任何权限错误或上线验证失败都明确失败，不能把git push当作上线。

运行：

    node data-pipeline/auto/test.mjs
    node data-pipeline/auto/refresh.mjs
    node data-pipeline/auto/refresh.mjs --force

技术断点与公开来源待核队列保存在`.cache/metalab-auto`，不提交到网站；不会读取或上传浏览器个人战绩。中文更新日志仍保存在独立的owner-only网站。本采集任务与原有每周全面检查并存，不把新增资讯等同于所有卡池/赛事已经全部更新。
